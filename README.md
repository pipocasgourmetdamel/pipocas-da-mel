# Pipocas da Mel · Preços

App para calcular o custo de cada sabor, o preço de venda, orçamentos e a tabela de preços da
Pipocas Gourmet da Mel. Funciona no navegador do iPhone e pode ficar na tela de início como um app.

## Como publicar no GitHub (GitHub Pages)

1. Crie um repositório novo (por exemplo `pipocas-da-mel`) e envie todos os arquivos desta pasta.
2. No repositório: **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
4. Depois de 1 a 2 minutos o endereço aparece na mesma tela: `https://SEU-USUARIO.github.io/pipocas-da-mel/`.

## Como instalar no iPhone

1. Abra o endereço no **Safari**.
2. Toque em **Compartilhar** e depois em **Adicionar à Tela de Início**.

## Importante

- Os dados ficam salvos **só no aparelho** (localStorage). Use **Ajustes → Exportar backup** de vez em quando.
- Para publicar uma versão nova, troque o número em `CACHE` no arquivo `sw.js`.
- Fontes: Jost e Pinyon Script (licença SIL OFL, veja a pasta `fonts`).
